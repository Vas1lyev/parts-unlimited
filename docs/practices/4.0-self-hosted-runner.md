# Практическая работа 4.0 — Агент сборочного конвейера

## Результат

Для репозитория Parts Unlimited подготовлен локальный GitHub Actions runner как
функциональный аналог self-hosted агента Azure Pipelines. Агент использует
официальный пакет GitHub Actions Runner `2.338.2` для `macOS ARM64`.

Целостность архива проверена по опубликованной контрольной сумме SHA-256:

```text
25a065af409ffa317ab4d5a3b614dd15fc9c40f2172bc1b35a1b1258e919a388
```

## Безопасность

Runner регистрируется только для репозитория `Vas1lyev/parts-unlimited` и не
получает административных прав. Workflow имеет минимальное разрешение
`contents: read`, запускается вручную и ограничен десятью минутами.

Регистрационный токен не сохраняется в репозитории, документации или журналах.
Рабочий каталог агента размещён отдельно от исходного репозитория.

## Возможности агента

Стандартные метки GitHub выполняют роль возможностей Azure Pipelines:

- `self-hosted` — задание выполняется на управляемом нами агенте;
- `macOS` — операционная система агента;
- `ARM64` — архитектура Apple Silicon.

Дополнительно диагностический workflow проверяет доступность Git и Docker.

## Проверочный workflow

Файл `.github/workflows/self-hosted-runner-check.yml` содержит ручной workflow
`Self-hosted runner check`. Его задание:

1. выбирает только self-hosted агент с метками `macOS` и `ARM64`;
2. получает содержимое репозитория;
3. выводит имя, ОС и архитектуру runner;
4. проверяет версии Git и Docker.

Такой запуск подтверждает регистрацию агента, соответствие требуемым меткам и
готовность выполнять задания сборочного конвейера.

## Соответствие исходному заданию

Пул агентов Azure DevOps заменён набором self-hosted runners GitHub Actions,
PAT Azure DevOps — краткоживущим регистрационным токеном GitHub, а системные и
пользовательские возможности — метками runner и диагностикой окружения.
