## Настройки runner

Runner зарегистрирован для репозитория `Vas1lyev/parts-unlimited`. Workflow
имеет разрешение `contents: read`, запускается вручную и ограничен десятью
минутами.

Регистрационный токен не сохраняется в репозитории, документации или журналах.
Рабочий каталог агента размещён отдельно от исходного репозитория.

## Возможности агента

Runner зарегистрирован с метками:

- `self-hosted` — задание выполняется на управляемом нами агенте;
- `macOS` — операционная система агента;
- `ARM64` — архитектура Apple Silicon.

Дополнительно диагностический workflow проверяет доступность Git и Docker.

## Проверочный workflow

Файл `.github/workflows/self-hosted-runner-check.yml` содержит ручной workflow
`Self-hosted runner check`. Его задание:

1. выбирает только self-hosted агент с метками `macOS` и `ARM64`;
2. получает содержимое репозитория;
3. выводит имя, ОС и архитектуру runner;
4. проверяет версии Git и Docker.

## Проверка выполнения

24 ноября 2026 года одноразовый runner `mirea-macos-arm64` подключился к GitHub,
принял задание `Runner diagnostics` и завершил его со статусом `Succeeded`.
Проверены окружение `macOS ARM64`, доступность Git и доступность Docker.

После выполнения задания runner удалил локальные файлы `.credentials` и
`.runner`, завершился с кодом `0` и автоматически снялся с регистрации.
