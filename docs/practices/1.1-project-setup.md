# Practice 1.1 - Project setup

## Result

The Parts Unlimited workspace has been initialized on GitHub as the equivalent
of an Azure DevOps organization and project.

## Completed setup

- The existing GitHub account and profile are used for project ownership.
- A public repository named `parts-unlimited` has been created.
- The repository has a concise description and relevant topics.
- Git is configured with `main` as the default branch.
- The initial project documentation and branding are version controlled.
- A private GitHub Project named `Parts Unlimited` is linked to the repository.
- Issues and Projects are enabled for future planning exercises.
- GitHub Wiki is enabled and contains the project home page.
- The four-person project team and areas of responsibility are documented in
  the Wiki.
