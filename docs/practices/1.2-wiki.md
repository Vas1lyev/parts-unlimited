# Практическая работа 1.2 - Работа с GitHub Wiki

## Результат

Для проекта Parts Unlimited настроена отдельная
[GitHub Wiki](https://github.com/Vas1lyev/parts-unlimited/wiki). Wiki является
самостоятельным Git-репозиторием и поддерживает страницы, историю изменений,
поиск, навигацию и локальное редактирование.

## Созданные страницы

- «Домашняя»;
- «Начало работы»;
- «Окружение для разработки системы»;
- «Наша команда»;
- «Предстоящие события»;
- «События января»;
- «События февраля».

## История изменений

Первая редакция страницы «Окружение для разработки системы» содержала
Team Foundation Server 2018. В следующей редакции указан Azure DevOps. Обе
версии доступны в истории коммитов.

## Навигация и порядок

Файл `_Sidebar.md` задаёт иерархию и порядок страниц. Январские события
расположены перед февральскими. Файл `_Footer.md` содержит ссылки на исходный код
и план проекта.

## Редактирование как кода

Wiki клонирована локально из отдельного репозитория:

```text
https://github.com/Vas1lyev/parts-unlimited.wiki.git
```

Страницы созданы как Markdown-файлы, зафиксированы несколькими коммитами и
опубликованы командой `git push`.
