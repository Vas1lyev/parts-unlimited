# Практическая работа 1.2 - Работа с GitHub Wiki

## Результат

Для проекта Parts Unlimited настроена отдельная
[GitHub Wiki](https://github.com/Vas1lyev/parts-unlimited/wiki). Wiki является
самостоятельным Git-репозиторием и поддерживает страницы, историю изменений,
поиск, навигацию и локальное редактирование.

## Созданные страницы

- «Домашняя»;
- «Начало работы»;
- «Окружение для разработки системы»;
- «Наша команда»;
- «Предстоящие события»;
- «События января»;
- «События февраля».

## История изменений

Страница «Окружение для разработки системы» была создана с упоминанием
Team Foundation Server 2018, после чего отдельной ревизией выполнена замена на
Azure DevOps. Сообщения коммитов позволяют найти и сравнить обе версии страницы.

## Навигация и порядок

Файл `_Sidebar.md` задаёт иерархию и порядок страниц. Январские события
расположены перед февральскими. Файл `_Footer.md` содержит ссылки на исходный код
и план проекта.

## Редактирование как кода

Wiki клонирована локально из отдельного репозитория:

```text
https://github.com/Vas1lyev/parts-unlimited.wiki.git
```

Страницы созданы как Markdown-файлы, зафиксированы несколькими коммитами и
опубликованы командой `git push`. Таким образом продемонстрировано редактирование
Wiki через обычный Git-процесс.

## Соответствие средств GitHub и Azure DevOps

- Отдельный Wiki-репозиторий GitHub заменяет публикацию репозитория Docs как Wiki.
- `_Sidebar.md` заменяет файл `.order` и одновременно задаёт вложенность страниц.
- История Git-коммитов заменяет список ревизий Azure DevOps.
