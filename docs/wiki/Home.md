# Parts Unlimited

Parts Unlimited is an educational web application that represents an online
auto-parts store. The project is used to demonstrate a complete software
engineering workflow: documentation, agile planning, source control, automated
builds, tests, and release planning.

## Purpose

The system will provide a small but realistic domain for the laboratory work.
Planned scenarios include browsing products, viewing learning materials, and
tracking delivery-related features and integrations.

## Project workspace

- Source code and version history are stored in GitHub.
- Work items are managed with GitHub Issues and GitHub Projects.
- Continuous integration is implemented with GitHub Actions.
- Delivery dates, dependencies, and workload are modeled in GanttPRO.
